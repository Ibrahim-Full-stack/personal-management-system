Personal Management System

A PHP & MySQL web application designed to manage personnel records through a simple, organized, and responsive dashboard.

Features

- Secure Admin Login & Logout.
- Personnel Records Management.
- Add, View, Edit, and Delete Records.
- Automatic Age Calculation.
- Automatic Service Duration Calculation.
- Search and Filter Records.
- Dashboard Statistics.
- Reports and Printing.
- Responsive Design for Mobile and Desktop.
- Arabic RTL Interface.

Technologies Used

- PHP
- MySQL
- PDO
- HTML5
- CSS3
- JavaScript

Requirements

- XAMPP
- PHP 8.0 or later
- MySQL
- Web Browser

Installation

1. Download or clone this repository.

2. Place the project inside the "htdocs" folder.

3. Create a MySQL database.

4. Import the database structure.

5. Configure your database connection in:
   
   "config/database.php"

6. Open the project in your browser:
   
   "http://localhost/Personal_Management/"
